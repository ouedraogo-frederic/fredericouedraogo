# Frédéric OUEDRAOGO — Academic Website

Personal academic website designed for GitHub Pages.

## Files

- `index.html` — homepage
- `publications.html` — publications and scientific activities
- `assets/css/style.css` — design
- `assets/js/main.js` — small interactions
- `assets/images/` — place your profile photo here later

## GitHub Pages

Repository name:

`ouedraogo-frederic.github.io`

Upload the contents of this folder to the repository root.

The site should then be available at:

`https://ouedraogo-frederic.github.io/`

## Adding a profile photo

Place an image in `assets/images/` and replace the `FO` placeholder in `index.html` with an `<img>` element.
